      If a Songsterr link won't load

      Songsterr sometimes blocks other websites from reading its tabs. When that happens, any of these will still work:

      Use the bookmark

      1. Drag Tab to Sheet to your bookmarks bar.
      2. Open the song on songsterr.com (open it now) and click the bookmark.

      Use your own relay

      A relay is a tiny free service that fetches from Songsterr for this page. The setup steps take a few minutes. If you have one, you can paste its address here:

      Run it on your computer

      With Node.js installed, npm install then npm start in a copy of the project. Links always work there.
